# Shift Tracker 📊

A beautiful, responsive web app to track your work shifts, calculate total hours, and never get underpaid again.

## Features

✅ **Calendar View** - See all your shifts at a glance
✅ **Easy Logging** - Click any date and select shift type from dropdown
✅ **Shift Types**:
   - Regular Shift (7.5 hours)
   - Overtime (custom hours)
   - Sick Day
   - Off Day
✅ **Monthly Analytics** - Total hours, overtime, sick days
✅ **Export Data** - Download as CSV for proof
✅ **Mobile-Friendly** - Works perfectly on phone, tablet, and desktop
✅ **Offline** - Data stored locally in your browser

## Getting Started

### Local Development

```bash
git clone https://github.com/Ainiyaer/shift-tracker.git
cd shift-tracker
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Deploy to Vercel

1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import this repo
4. Click Deploy (it's that simple!)

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Storage**: Browser LocalStorage
- **Icons**: Lucide React
- **Date Handling**: date-fns
